# Führungsverhalten analysieren

Interaktive Fallarbeit zum Modell des interpersonalen Lehrerverhaltens für das Seminar Klassenführung (WiSe 2026/27).

## Veröffentlichen über GitHub Pages

1. Neues Repository auf GitHub anlegen, zum Beispiel `fallarbeit-fuehrungsverhalten`.
2. Die Datei `index.html` (und diese README) in das Repository hochladen.
3. Unter **Settings › Pages** als Quelle den Branch `main` und den Ordner `/ (root)` wählen und speichern.
4. Nach etwa einer Minute ist die Übung unter `https://<benutzername>.github.io/fallarbeit-fuehrungsverhalten/` erreichbar. Diesen Link können Sie mit der Lerngruppe teilen.

## Hinweise

Die Seite benötigt keinen Server und speichert keine Daten außerhalb des Browsers der Studierenden. Eingaben bleiben im jeweiligen Browser erhalten und lassen sich als PDF, als Word-Datei sowie als Sicherungsdatei herunterladen. Für PDF und Word wird beim Klick jeweils eine Bibliothek von cdn.jsdelivr.net geladen. Ohne Internetverbindung öffnet sich für das PDF der Druckdialog mit einer eigenen Druckansicht, und statt der Word-Datei entsteht eine Word-kompatible `.doc`-Datei.

Die Seite ist für Laptop, Tablet (Touch) und Smartphone ausgelegt. Textfelder wachsen mit dem Inhalt mit, und im PDF werden alle Einträge vollständig mit Zeilenumbrüchen und Seitenwechseln ausgegeben.

Die Fälle und Musteranalysen stehen am Anfang des Skripts im Objekt `DATA` und können dort angepasst werden.
